This website was developed to help children and teens grow into helpful and productive people. It is highly customizable. 
Parents and children can work together to develop the lists of chores/tasks/achievements.
These can be monetized or converted to rewards however one chooses.
The goal is to use the tool to start lifelong conversations about how to be helpful to those around you.
Avoid using the tool as a means to manipulate or punish without transparency. 
Before using it, speak to your kids about the financial benefits of the tool, your reasons for wanting to use it, and how they can use it to become autonomous.
